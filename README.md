# Notes on Agentic AI

My thoughts on agentic AI and what it does to enterprise work. Written as I went — notes, not a finished framework.

These were first posted on LinkedIn: [linkedin.com/in/young-rex](https://www.linkedin.com/in/young-rex)

Files are numbered in the order they were written.
